Build a production‑grade centralized Authentication and Authorization microservice using NestJS.

This service must act as a standalone Identity and Authorization platform used by multiple independent applications (microservices such as chat, blog, trello clone, AI SaaS).

The system must allow each connected application to choose which authorization models it wants to use.

Supported authorization models:

RBAC (Role Based Access Control)
ABAC (Attribute Based Access Control)
PBAC (Policy Based Access Control)
ACL (Access Control List)
ReBAC (Relationship Based Access Control)
Each application must be able to enable or disable these models individually.

Example:

Application A → RBAC + ABAC

Application B → RBAC only

Application C → PBAC + ReBAC


The authorization engine must dynamically evaluate only the enabled models for that application.

Example request:

{

“enabledModels”: [“RBAC”, “ABAC”],

“board”,

“card”

],

“create”,

“delete”

]

}

AUTHORIZATION ENGINE

Create a central service:

AuthorizationEngineService

Method:

evaluateAccess(request)

Request format:

{

userId: string

service: string

resource: string

action: string

resourceId?: string

context?: object

}

Before evaluating permissions, the engine must load the service configuration and determine which models are enabled.

Evaluation pipeline example:

if service uses:

RBAC + ABAC

then run:

RBAC check

ABAC check

If any rule grants access → ALLOW

Otherwise → DENY
